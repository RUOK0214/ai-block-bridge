# AI Block Bridge 0.1.19

Minecraft Java Edition **26.2 · Fabric**

## 이번 변경

0.1.18의 기록 최적화 기능을 모두 유지하면서 파일 팔레트 코드화를 추가한 통합 버전입니다.

- 구조 및 타임라인 엔티티 기록
- 엔티티 Age/Motion 변화 제외
- 엔티티 NBT 변경분만 기록
- 짧은 엔티티 ID
- 짧은 블록 상태 ID
- 블록 NBT 변경분 및 인벤토리 슬롯별 기록
- 기록 옵션 전용 화면과 영역 설정 화면
- 저장 폴더 열기
- **파일 팔레트 코드화: 기존 형식과 전환 가능**

팔레트 코드화는 Minecraft의 구형 숫자 ID를 사용하지 않습니다. 파일 앞부분에 해당 파일에서 사용하는 블록 상태를 한 번 선언하고 데이터 행에서 짧은 숫자로 참조합니다. 대응표가 파일 안에 있으므로 AI가 별도의 ID 목록을 알 필요가 없습니다.

코드화된 `structure.txt`는 다시 불러와 문법 검사와 월드 붙여넣기에 사용할 수 있습니다. `timeline.txt`에서는 기존의 짧은 블록 상태 ID·NBT 변경분 옵션과 함께 사용할 수 있습니다. 기본값은 기존 형식입니다.

## 설치

1. Assets에서 **ai-block-bridge-0.1.19.jar**를 다운로드합니다.
2. Minecraft 26.2용 Fabric Loader **0.19.5 이상**, Fabric API **0.160.0+26.2 이상**, Java 25 이상이 필요합니다.
3. 이전 AI Block Bridge JAR을 제거한 뒤 새 JAR을 `mods` 폴더에 넣습니다.
4. 멀티플레이는 서버와 클라이언트 모두 같은 버전을 설치합니다.

자동 빌드, 단위 테스트, 서버 테스트와 클라이언트 화면 테스트를 통과한 파일입니다. 중요한 월드에서는 복사본으로 먼저 시험하세요.
