# AI Block Bridge 0.1.20

Minecraft Java 26.2 / Fabric용입니다.

## 변경 사항

- 구조 화면의 도구 줄을 `영역 → 스크립트 | 스크립트화 취소 | 엔티티 포함 | 기록 옵션` 순서로 배치했습니다.
- 구조 화면에서 바로 기존 기록 옵션 화면을 열어 엔티티·블록 기록 압축 설정을 조정할 수 있습니다.
- 기존 v0.1.19의 파일 팔레트 코드화 및 v0.1.18의 기록 기능을 모두 유지합니다.

## 설치

1. 기존 AI Block Bridge JAR를 제거합니다.
2. `ai-block-bridge-0.1.20.jar`를 Minecraft 26.2 Fabric의 `mods` 폴더에 넣습니다.
3. Fabric API 0.160.0+26.2 이상이 필요합니다.

싱글플레이 월드 편집은 치트 허용, 멀티플레이는 서버·클라이언트 양쪽 설치와 OP 레벨 4가 필요합니다.
