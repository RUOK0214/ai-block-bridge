# AI Block Bridge 0.1.12 — 엔티티 기록 옵션

Minecraft Java 26.2 / Fabric. 클라이언트와 서버의 모드 버전을 함께 맞춰 주세요.

- 구조 저장과 타임라인 기록에 각각 엔티티 포함 옵션 추가, 기본 꺼짐.
- 엔티티 UUID, 종류, 상대 위치, 전체 저장 NBT 기록.
- 타임라인의 초기 상태와 영역 진입·이동·상태 변경·이탈 추적.
- 플레이어 제외, 엔티티 수와 전체 기록 용량 제한 적용.
- 기존 블록 스크립트 호환 유지. 엔티티 주석은 분석용이며 붙여넣기로 생성하지 않음.

떨어지는 콘크리트 가루나 아이템 이동을 분석하려면 두 옵션을 켜고 기록한 뒤 기록 세트를 저장하세요.
