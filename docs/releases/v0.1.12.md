# AI Block Bridge 0.1.12

Minecraft Java Edition **26.2 · Fabric**

## 이번 변경 / Changes

- **저장 형식: 기존 형식 / 코드화 형식(토큰 절약)** 전환을 추가했습니다.
- 코드화 형식은 파일별 로컬 팔레트에 블록 이름·상태를 한 번만 선언하고 데이터 행에서는 짧은 숫자를 사용합니다.
- 영역 캡처와 틱 기록 세트의 `structure.txt`, `timeline.txt`에 같은 선택을 적용합니다.
- 코드화된 구조 스크립트도 문법 검사, 다시 불러오기와 월드 붙여넣기를 지원합니다.
- 구형 Minecraft 숫자 ID를 사용하지 않으므로 버전별 ID 혼동 없이 파일 자체만으로 해석할 수 있습니다.
- 기존 읽기 쉬운 형식은 그대로 유지되며 기본값입니다.

Added a switchable token-saving local-palette format. Each file declares its block states once and uses short numeric aliases in data rows. It applies to region captures and both files in a recording set. Coded structure scripts can be validated, imported, and pasted back into the world. The readable format remains the default.

## 다운로드와 설치

1. Assets에서 **ai-block-bridge-0.1.12.jar**를 다운로드합니다. 압축을 풀지 마세요.
2. Minecraft 26.2용 Fabric Loader **0.19.5 이상**, Fabric API **0.160.0+26.2 이상 중 26.2 호환 버전**, Java 25 이상이 필요합니다.
3. 기존 AI Block Bridge JAR을 제거하고 새 JAR을 `mods` 폴더에 넣습니다.
4. 멀티플레이는 서버와 클라이언트 모두 같은 버전을 설치합니다.

중요한 월드에서는 복사본으로 먼저 시험하세요. 치트 또는 OP 4 권한이 필요합니다.
