# AI Block Bridge 0.2.1

Minecraft Java 26.2 / Fabric · RUOK0214 · MIT

## 메뉴 개편

- 구조·타임라인·테스트의 상단 메뉴를 구조 / 타임라인 / 테스트 / AI 요청문으로 통일했습니다. 도움말과 닫기는 오른쪽 위에 있습니다.
- 모든 편집 화면에서 영역 설정을 열 수 있습니다. 영역 설정에는 축별 입력 제목과 적용 전 영역 미리보기를 추가했습니다.
- 구조·타임라인에 저장 형식: 기본 / 코드화 바로가기를 추가했습니다. 다음 캡처·기록에 적용되며 현재 편집 중인 내용을 변환하지 않습니다.
- 구조 화면의 영역 → 스크립트 / 스크립트화 취소 / 엔티티 포함 / 기록 옵션 배치를 유지했습니다.
- 기록 옵션을 일반 / 블록 / 엔티티 탭으로 통합했습니다. 일반 탭에서 저장 형식과 구조·타임라인의 엔티티 포함 여부를 설정합니다.
- 기록 중이거나 기록 수령 대기 중인 상태에는 옵션을 잠그고 이유를 표시합니다.
- 좁은 화면에서는 구조 실행 도구를 두 줄로 배치합니다. 버튼 위에 마우스를 올리면 전체 이름을 확인할 수 있습니다.
- 테스트 화면에 문법 검사와 편집 취소(Ctrl+Z)를 추가했습니다. 파일 도구는 편집 화면 아래쪽으로 통일했습니다.
- AI 요청문과 결과 화면의 복귀 버튼을 돌아가기로 표시합니다.

## 설치

- 기본 기능: ai-block-bridge-0.2.1.jar
- 파일 자동화가 필요할 때만 추가: ai-block-bridge-2-0.2.1.jar (기본 모드 필요)
