# AI Block Bridge 0.2.2

Minecraft Java 26.2 / Fabric · RUOK0214 · MIT

- 스크립트에 `# unlisted: keep|clear`를 추가했습니다. 생략하면 기존처럼 keep입니다. clear는 현재 선택 영역에서 적지 않은 블록과 통 내용물을 삭제합니다.
- 구조 편집창에서 현재 모드를 표시하고, clear 붙여넣기 확인 창에 영역 삭제를 안내합니다. 한국어·영어를 지원합니다.
- clear 붙여넣기 취소는 삭제된 블록·NBT·아이템과 새 블록 위치의 원래 공기를 복원합니다. 복원 데이터 한도 초과와 잘못된 지시자는 월드 변경 전에 거부합니다.
- 애드온은 JSON clear와 스크립트 clear를 OR로 처리합니다. JSON clear의 기존 기본값 true는 유지합니다. 0.2.2 애드온은 기본 모드 0.2.2 이상이 필요합니다.
- 회로 테스트의 레버·버튼 set이 부착 블록에도 필요한 업데이트를 전달하도록 수정했습니다. 전원과 부착 방향이 그대로이면 불필요한 업데이트를 추가하지 않습니다.

기본 설치: `ai-block-bridge-0.2.2.jar`. 폴더 자동화가 필요할 때만 `ai-block-bridge-2-0.2.2.jar`도 설치하세요. 기존 JAR는 교체합니다.

되돌리기는 기본 모드에서 마지막 붙여넣기 한 번에만 적용되는 메모리 기록입니다. 접속 종료 시 사라지며 디스크 복구 파일이 아닙니다. 애드온 실행에는 이 취소 기록이 생성되지 않습니다.
