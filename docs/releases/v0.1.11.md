2. Minecraft 26.2용 Fabric Loader **0.19.5 이상**, Fabric API **0.160.0+26.2 이상 중 26.2 호환 버전**을 설치합니다. Java 25 이상이 필요합니다.
3. JAR 파일을 해당 게임 프로필의 `mods` 폴더에 넣고 Fabric으로 실행합니다. 이전 AI Block Bridge JAR은 먼저 제거하세요.
4. 멀티플레이는 서버와 클라이언트 모두 같은 모드 버전을 설치합니다.

Mod Menu는 선택 사항입니다. 설치하면 모드 소개, 사용법, 디스코드 링크를 볼 수 있습니다.

## 빠른 사용법
1. 블록을 바라보고 `[` / `]`로 영역의 두 모서리를 선택합니다.
2. `B`로 편집기를 열어 구조를 캡처하거나 AI 요청문을 복사합니다.
3. `N`으로 기록을 시작하고 회로를 작동시킨 뒤, 다시 `N`으로 종료합니다.
4. 타임라인 화면의 **기록 세트 저장**을 누르면 새 폴더에 `structure.txt`와 `timeline.txt`가 저장됩니다. 두 파일을 AI 대화에 함께 첨부하세요.
5. AI가 만든 블록 배치 스크립트를 블록 편집기에 넣어 적용하고 실제 작동을 확인합니다.

`\`는 선택 영역 표시 전환입니다. 단축키는 설정 → 조작에서 변경할 수 있습니다.

## 포함 기능과 사용 범위
- 영역 구조·블록 상태·블록 엔티티 NBT 캡처
- 틱별 변화 기록, 호퍼 쿨다운 변화 필터, 기록 제한 도달 알림
- 시작 시점의 구조와 작동 기록을 한 폴더에 저장
- 블록 배치 스크립트 적용 및 되돌리기
- 분석·설계·수정용 AI 요청문 복사
- 한국어·영어 UI, 모드 아이콘 및 사용 안내

치트 또는 OP 4 권한이 필요합니다. AI 서비스 연결은 파일 첨부와 요청문 복사 방식이며 자동 API 연결은 아닙니다. 틱 기록은 서버 틱 단위의 상태 변화이므로 한 틱 안에서 일어났다가 사라진 모든 중간 변화까지 기록하는 것은 아닙니다.

기록 세트 저장은 가장 최근에 가져온 기록의 **원본**을 저장합니다. 편집한 타임라인은 기존 내보내기로 따로 저장하세요. 제한에 도달하면 알림 후 기록을 가져와 저장할 수 있습니다.

## English

AI Block Bridge exports block structures and tick-by-tick changes as text, and applies AI-generated block placement scripts in Minecraft.

### Install
- Download **ai-block-bridge-0.1.11.jar** from Assets. Do not unzip it.
- Requires **Minecraft Java 26.2**, **Fabric Loader 0.19.5+**, a **26.2-compatible Fabric API 0.160.0+26.2 or newer**, and **Java 25+**.
- Put the JAR in your game profile's `mods` folder. Remove older AI Block Bridge JARs first.
- For multiplayer, install the same version on both server and client. Mod Menu is optional.

### Quick start
1. Aim at blocks and press `[` / `]` to select two corners.
2. Press `B` to open the editor, capture a structure, or copy an AI request.
3. Press `N` to record, operate the circuit, and press `N` again to stop.
4. Choose **Save recording set** to create a folder containing `structure.txt` and `timeline.txt`. Attach both to your AI chat.
5. Apply the returned placement script in the block editor, then verify the circuit in-game.

Press `\` to toggle the selection overlay. Keys can be changed in Options → Controls.

Requires cheats or OP level 4. This mod uses copied prompts and file attachments, not automatic AI API requests. Recording captures server-tick state changes, not every intermediate event within a tick. Recording-set export saves the latest retrieved original pair; export edited timeline text separately.

Features include structure/NBT capture, tick recording and limit notices, paired folder export, script application and undo, AI prompt templates, and Korean/English UI. The distributed JAR passed automated build, unit, server game and client smoke tests.
