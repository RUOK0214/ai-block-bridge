# AI Block Bridge 0.2.0

Minecraft Java 26.2 / Fabric / Java 25.

- 구조 안정화 점검, 자동 테스트 대본, NBT 필드 팔레트 추가.
- 오류 줄 표시, 파일 종류 감지, 선택 영역 이동 추가.
- AI Block Bridge 2 자동화 애드온을 별도 JAR로 제공.
- 긴 테스트의 클라이언트 응답 대기를 15분으로 확장.
- 자동화 중지 및 서버 종료 시 요청 취소와 틱 속도 복원.
- 요청은 processing 폴더에서 처리하고 응답 저장 후 done으로 이동.
- 중단된 processing 요청은 자동 재실행하지 않음.
- 안정화 차이 출력은 최대 1,000행 / 500,000자, 전체 차이 수는 유지.
- 테스트 대본의 블록 상태는 영역 삭제 전에 검증.
- 중단된 테스트를 PASS로 표시하지 않도록 수정.

기본 모드만 사용하면 기존 텍스트 교환 방식입니다.
자동화가 필요할 때만 기본 모드와 애드온 JAR를 함께 설치하세요.
애드온은 AI API에 연결하지 않으며 별도 로컬 프로그램이 요청 파일을 작성해야 합니다.

자동화는 테스트 전용 월드에서 사용하세요. 영역 삭제·배치·테스트는 실제 월드를 바꾸며
취소는 이미 변경한 월드를 복원하지 않습니다. tickRate는 서버 전체에 적용됩니다.
자세한 요청 형식과 복구 절차는 docs/automation.md를 참고하세요.
